# SIP 心智模型

一句话：这一页不记"SIP 有什么"，只记**"为什么长这样、以及它明确不做什么"**——
后面每个"这个功能该不该在 SIP 层实现"的判断都查这页。

> **状态：draft，一个答案都还没有。**
> 这不是漏写：本页的正文必须由**读过 §1–§6 的人**逐条填，且每条带锚点。
> 按 `AGENTS.md` §3，事先凭印象填等于制造幻觉。

## 为什么要这一页

`plan.yaml` 的 α–ε 是按**实现依赖**排的（先写 parser 再写事务）。
但学习还有第二条线：**认知依赖**——不知道 SIP 的边界与取舍，写 parser 时就只是"照 ABNF 抄"，
遇到"为什么头域要限制字符集""为什么 Via 要逐跳追加"这类问题会没有判断力。

Phase 0 就是补这条线，产出物就是本页。
