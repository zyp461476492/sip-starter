SIP 头域在语法与语义上都与 HTTP 头域相似。具体而言，SIP 头域的语法遵循 [H4.2] 对 message-header 的定义，以及把头域跨多行扩展的规则。不过 HTTP 用隐式空白与折叠（folding）来表达后者，而本规范遵循 RFC 2234 [10]，只把**显式**的空白与折叠作为语法的一部分。

[H4.2] 还规定：同一字段名、值为逗号分隔列表的多个头域，可以合并为一个头域。这条对 SIP 同样适用，但由于语法不同，具体规则也不同。具体来说，凡语法形如

```
      header  =  "header-name" HCOLON header-value *(COMMA header-value)
```

的 SIP 头域，都允许把同名头域合并成逗号分隔列表。Contact 头域允许逗号分隔列表，但头域值为 `"*"` 时除外。
