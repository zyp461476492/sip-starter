Bob 在启动时注册。消息流如图 9 所示。请注意：注册通常需要的认证，这里为简明起见没有画出。

```
                  biloxi.com         Bob's
                   registrar       softphone
                      |                |
                      |   REGISTER F1  |
                      |<---------------|
                      |    200 OK F2   |
                      |--------------->|

                  Figure 9: SIP Registration Example
```

F1 REGISTER Bob -> Registrar

```
       REGISTER sip:registrar.biloxi.com SIP/2.0
       Via: SIP/2.0/UDP bobspc.biloxi.com:5060;branch=z9hG4bKnashds7
       Max-Forwards: 70
       To: Bob <sip:bob@biloxi.com>
       From: Bob <sip:bob@biloxi.com>;tag=456248
       Call-ID: 843817637684230@998sdasdh09
       CSeq: 1826 REGISTER
       Contact: <sip:bob@192.0.2.4>
       Expires: 7200
       Content-Length: 0
```

该注册在两小时后过期。注册服务器回一个 200 OK：

F2 200 OK Registrar -> Bob

```
        SIP/2.0 200 OK
        Via: SIP/2.0/UDP bobspc.biloxi.com:5060;branch=z9hG4bKnashds7
         ;received=192.0.2.4
        To: Bob <sip:bob@biloxi.com>;tag=2493k59kd
        From: Bob <sip:bob@biloxi.com>;tag=456248
        Call-ID: 843817637684230@998sdasdh09
        CSeq: 1826 REGISTER
        Contact: <sip:bob@192.0.2.4>
        Expires: 7200
        Content-Length: 0
```

> 译注：注意 F2 里 To 被注册服务器加了 `tag=2493k59kd`，而 From 没有——注册是一个非 INVITE 事务、也是一个“由 UC 发起、由 registrar 应答”的普通请求，两点在这两条报文里能直接看到。另外 `Expires: 7200` 既出现在请求里（这是本次注册想要的存活时间），也出现在响应里（这是服务器实际给出的值）。
