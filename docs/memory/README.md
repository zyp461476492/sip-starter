> 一句话：本地项目记忆的写入规则。什么进这里、什么不许进、多久清理。

# memory/

这里放**关于这个仓库本身**的记忆，不是 SIP 知识（那是 `wiki/` 的事），
也不是约束（那是 `AGENTS.md` 的事）。

## 四个文件，四种记忆

| 文件 | 记什么 | 写入时机 | 腐坏方式 | 清理规则 |
|---|---|---|---|---|
| `facts.md` | 确定性事实与坑：症状 → 结论 → 证据 | 踩坑当天 | 过期不删 | **被推翻就删或标 superseded**，允许过期即删 |
| `journal.md` | 时间线：每次会话/每次大改一条 | 会话末 append | 变流水账 | 单文件 > 500 行按 `journal-YYYY-MM.md` 归档 |
| `open-threads.md` | 未决问题、待验证假设、TODO | 随时 | 永不关闭 | 每条必须有触发条件或关闭日期，否则不许记 |
| `README.md` | 本文件：写入规则 | 规则变化时 | — | — |

`status.md`（在 `docs/`）不在这里：它是"当前状态快照"，每次覆盖，只写现在。

## 三条纪律

1. **facts 必须有证据**。没有"症状 + 证据"的观察不是事实，是猜测 → 进 `open-threads.md` 待验证。
2. **不许写凭证**。密钥、内网地址只记"在哪个配置项"，不记值。
3. **memory 会被新会话当权威读**（见 `AGENTS.md` §0）。写错比不写更糟——所以宁可少写。

## 与 skill / 外部记忆的关系

`facts.md` 里那种"本机已确认的网络事实"和 AI 助手的 skill 是同一类东西：
**带证据的确定性事实**，复用率最高，也最容易腐坏（世界变了，你还信它）。
凡是从外部抄来的事实，都要带日期。
